# 几何契约模板（放进值规范，例如 `<design-root>/design-system/README.md` 的一个小节）

画板和代码必须测量同一个盒子，否则每一次比对都会漂移。这份契约规定两边各自把什么当作一个盒子。上游的画板扫描（[../alignment.md](../alignment.md)）和下游的屏幕几何比对（[../screen-conformance.md](../screen-conformance.md)）都按这一份契约测量，不各写一套。

复制下表，把 `<…>` 换成项目自己的 token 名和数值；数值只写在 token 规范里，这里只引用 token 名。

| 对象 | 布局盒 | 代码侧 | 设计文件侧 |
|---|---|---|---|
| 文字 | 字号 × 该角色的 token 行高（例：`<line-height-title>` 用于 ≥ `<N>` 的字号，`<line-height-body>` 用于其余）。多行 = 行数 × 单行盒 | 元素的 line box，与字体无关 | 只有文字图层的行高等于 token 值时才成立。Penpot 默认行高是 1.2，Figma 默认 auto，都不是 token 值。画板改好之前，文字一律按**盒子的垂直中心**比对，不按顶边 |
| 字体 | 字形在 line box 内的位置、文字宽度取决于字体 | 列出项目的字体 token；关掉 font synthesis | 画板使用 app 实际打包的字体；若用替身字体，只比盒子和 line box，不比字形宽度 |
| 字形宽度 | 布局不依赖它 | 盒子包住或换行它的文字 | 不按某一段文字的宽度画固定盒；多行文字是一个自动高度的图层，不手工断行 |
| 字号缩放 | 契约和比对只在系统字号 1.0 下成立 | 字号用可缩放单位（sp / Dynamic Type / rem），间距、圆角、图标、触控区用固定单位 | 画板只画字号 1.0；带文字的盒子随文字长高，不写死高度，除非组件规范写了 clamp |
| 图标 | 图标盒 = token 图标尺寸（例：`<16/20/24>`） | 图标组件按 token 尺寸渲染整个 viewBox | 图标资产实例按 token 尺寸摆放，frame 即图标盒；不按字形的可见像素测量 |
| 触控区 | 视觉盒就是画板上画出来的盒子；点击区向外扩到 `<touch-min>`，**不占布局空间** | 用外扩的 padding、hit-test 扩展或伪元素实现，不撑大布局 | 不画点击区。例外：没有可见边框的单独图标按钮，按 `<touch-min>` 见方画、图标居中（顶栏返回、面板关闭） |
| 顶部安全区 | 画板 y = 0 是安全区顶边；画板不画状态栏 | 根容器加上平台的 top inset | 顶栏之上什么都不画 |
| 底部安全区 | 画板底边 = 系统导航区的顶边 | 固定底栏在自身下方加 bottom inset | 不画 |
| 宽度 | 内容宽 = viewport − 2 × `<page-margin>` | 流式布局，不写死画板宽度 | 满宽（贴边）：顶栏、底栏、列表行（自带内边距）、底部面板。填满内容宽：输入框、提示条、卡片、分节标题、满宽主按钮、宫格。包住内容：chip、分段控件、非满宽按钮 |
| 组件实例 | 保持它自己的盒子（尺寸是组件规范的一部分） | 组件根节点的 bounds | 实例根图层 |
| 普通容器 | 没有可见填充、描边或边框装饰的容器 = 子元素的并集 | 同左 | 同左；装饰层（手绘框、高亮标记）不计入盒子 |
| 旋转图层 | 取旋转后的外接盒 | 同左 | 同左 |

## 参考 viewport

- 参考尺寸 = 画板尺寸（例：`<360×800>` 设计单位），渲染倍率 `<scale>`。
- 机器比对在哪个渲染环境里做（JVM 渲染器、模拟器、Chromium 移动 viewport……），写清楚它是不是真机的代理；代理关系只在真机上确认一次，确认前标为未验证。
- 真机或模拟器实测的 inset、字号缩放结果只记一次，带日期和环境描述；不写设备序列号或个人信息。
